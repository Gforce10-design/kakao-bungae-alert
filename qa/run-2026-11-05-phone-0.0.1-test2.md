## Disclosures (test-method deviations)

- **SIMULATED KakaoTalk notifications.** All chat notifications came from stub apps `com.kakao.talk` and `com.example.other` (notifier stubs posting via `am broadcast qa.POST`), not real KakaoTalk. Allowed by the pack/fixtures approach used in the PR #7 run; no real Kakao account or phone used.
- **Permissions granted through adb**, not the Settings UI: `pm grant POST_NOTIFICATIONS`, `cmd notification allow_listener app.bungaealert/app.bungaealert.notify.KakaoNotificationListener`. (A first attempt used a wrong listener class name `app.bungaealert.KakaoNotificationListener`; it was removed again with `disallow_listener` before BA-13-3 was re-captured.)
- **Onboarding bypassed via root file edit** (`onboardingDone:true` in `shared_prefs/bungae_settings.xml`; the release build is not debuggable, so `adb root` was used instead of `run-as`). Watch rules seeded by writing `files/watch-rules.json` (qa-exact 수다방, qa-contains 자유, qa-ends 위하여~, qa-repeat 반복방 repeat-mode, qa-disabled 꺼진방 disabled, qa-empty '').
- **BA-07/08:** Gemini API judge enabled with a **fake key** typed via the UI (a fake key remains stored in the app; judge toggle still on at end of run); network blocked for the app uid with an iptables DROP rule, removed afterwards.
- **BA-09/BA-15:** BA-09 used real elapsed time (>10 min). BA-15 bypassed the 6 h update throttle by deleting `shared_prefs/bungae_update.xml`.
- **BA-14 / BA-15 limits:** ASCII keywords only (no Hangul via adb); keyword file missing/corrupt/empty cases produced by root file edits + app restart; no release with higher versionCode exists, so the "notify once" positive path was not exercised on this build.
- **First-launch network traffic:** the fresh install made 31 packets (UpdateCheckWorker -> GitHub) before the BA-11 counter was zeroed; BA-11 evaluates match processing only.
- Emulator environment: slow TCG emulator (taps/screenshots lag 1-5 min), Google apps disabled, animations off, stay-awake on. Previous PR #7 debug build of app.bungaealert was uninstalled first (data wiped), phone APK installed fresh (uid 10197). No Google sign-in attempted. emulator-5556 never observed. A temp screenshot file written by another agent in shared /tmp (not mine, showing unrelated content) was opened by mistake once; it was not used or copied as evidence.
