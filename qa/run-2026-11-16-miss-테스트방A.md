## Pipeline (why it was logged but did not ring)

1. Keyword gate passed: `선착순` is in the body, so `KeywordMatcher` accepted the notice and the pipeline scored it (`KakaoNoticePipeline`).
2. `ScoreClassifier.score()` returned meetup **30**, giveaway **18**.
3. `DecisionPolicy.relevant()` picked `PostType.MEETUP` because 30 > 18. History shows type **번개** via `typeShort(MEETUP)` in `Format.kt` (`recordType` falls back to the higher of `meetupScore` / `giveawayScore` when `alertType` is empty because no alert fired).
4. Default settings in `Stores.kt`: `sensitivity = 40`, `borderlineBand = 12`.
5. `Sensitivity.cutoff(40)` is `80 - (40 * 45 / 100)` = **62**. Low band is 62 − 12 = **50**. Score 30 < 50 → `ScoreZone.CLEAR_REJECT` → `alert = false`. The detection is still written to `detections.json`.

The sensitivity slider cannot work around this. The loosest setting is 100, cutoff **35**, and 30 is still below 35. Even in the borderline band, the no-judge fallback is `score >= cutoff`, which would also fail.

## Proposed fix (not applied, not pushed)

Goal: this class of “a seat opened, FCFS apply via DM” messages should score as **meetup ≥ 70** (above default cutoff 62), still ahead of giveaway, without lifting the existing low-score fixtures.

1. **Stop treating `못오시는 분` as 참석 권유.** Require that `오실\s*분` / `오시는\s*분` are not preceded by `못` / `안` (and the same with an optional space: `못 오시는 분`).
2. **Score vacancy as positive meetup intent**, e.g. `못\s*오시는\s*분`, `빈\s*자리`, `한\s*자리`, `취소한\s*분`, `빠진\s*분`, `추가\s*모집` — about +16.
3. **Widen `recruitPhrase`** with `신청\s*받` / `신청받` so `신청 받겠습니다` / `신청 받` counts as 모집 표현 (+16). Short standalone replies like `신청` remain capped by `isReplyOnly`.
4. **Give `모임` a meetup anchor only with context** (date, time, 선착순, 신청, or vacancy), weaker than 번개 (about +14…+16). Do not score bare `모임`.
5. **When meetup context already exists, add 선착순 to the meetup score** (e.g. “선착순 신청” +12…+14). Today 선착순 only feeds the giveaway lane, so a genuine meetup FCFS is under-scored and can be mis-typed if giveaway later rises.
6. Optional extras: `갠톡` / `개인톡` as an apply-channel bonus when other meetup signals exist; `\d{1,2}\s*분` as a short deadline only when paired with 선착순 or 신청, and never as `N분께`.

A target breakdown for the missed text after (1)–(5), without relying on the false 참석 권유: 날짜 12 + 모임(with date) ~16 + vacancy ~16 + 신청 받 16 + 선착순 신청 ~14 ≈ **74**, plus optional 갠톡. Keep `casualAndRepliesStayLow` green, especially `선착순으로 자리 맡았어? 지난번 모임` (past penalty must still hold it under 40).
