# 번개알림 실기기 테스트 시나리오 (S25 Ultra, 2026-11-05 작성)
대상: 최신 빌드(PR #7 1d1e017 = 0.0.1-test2, 또는 치프 보완 빌드). 에뮬레이터에서 못 본 항목 위주.

## 준비
- 진짜 카카오톡, 테스트용 단톡방 1개(본인+지인 1명 또는 부계정), 번개알림 감시방으로 지정
- 키워드: 번개, 선착순 (한글로 직접 입력)
- 화면 잠금 + 무음/진동 모드 둘 다 준비

## 시나리오
1. 실제 카톡 감지 (BA-01~05): 지인이 단톡방에 "오늘 7시 강남 번개 3명 모여요" 전송 → 알람 울림. 다른 방/광고 글은 무시.
2. 잠금·무음 상태 알람 (BA-10): 폰 잠금+무음에서 1번 반복 → 잠금화면 위로 알람, 소리 남. 손대지 않고 자동 종료 시간을 초시계로 측정(기준 180초).
3. 탭해서 열기: 알람 탭 → 카톡 해당 방으로 이동.
4. 중복 방지 (BA-09): 같은 글을 10초 안에 2번 → 알람 1번.
5. 배터리 최적화/재부팅: 폰 재부팅 후 앱을 열지 않은 상태로 1번 반복 → 감지되는지.
6. 한글 키워드 (BA-14): 키워드 추가/수정/삭제를 한글로, 중복 "번개" 입력 거부 확인.
7. 업데이트 알림 (BA-15): 치프가 versionCode 3 릴리스를 올리면 → 알림 1번만 뜨는지.
8. Grok 웹훅 + ntfy (BA-16): 실제 Grok Bot 웹훅 주소와 헤더 입력 → 경계 글 전송 → 답이 와서 알람 판정에 반영되는지, 걸린 시간 기록. Wi-Fi↔LTE 전환 후 다시 한 번.
9. 오프라인 (BA-11): 비행기 모드에서 1번 반복 → 점수만으로 정상 알람.
10. 10분 방치 후: 화면 끈 채 10분 두고 1번 반복 → 도즈 모드에서도 감지되는지.
